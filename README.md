# it-compliance-demo

Projekt pokazowy one-page strony dla marki IT Compliance (GDPR · NIS2 · AI Act · ISO 27001/42001), przygotowany na potrzeby prezentacji oferty wykonawczej.

- Kolorystyka i struktura wg wytycznych zleceniodawcy: granat #183B66, rubin #C91842, krem #FFF9F2
- Pełne RWD, subtelne animacje (z poszanowaniem prefers-reduced-motion)
- Formularz kontaktowy z walidacją, honeypotem i zgodą RODO
- Mechanizm zarządzania zgodami na cookies (banner + zarządzanie ze stopki)
- SEO: meta title/description, Open Graph, JSON-LD ProfessionalService
- Dostępność: semantyka, skip-link, focus-visible, kontrasty WCAG 2.2

**Demo** — treści zgodne z publicznym profilem kancelarii Gierada Sołtysek Strzelecki (inspektorzy.com); zdjęcia i biogramy docelowo dostarczy zleceniodawca.

Live: https://sayd1975-code.github.io/it-compliance-demo/
